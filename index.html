使用方式

  1. 時間軸結構：點擊八拍可再展開下面的小拍。播放可直接播放軌跡，左右鍵可切換前一個或後一個cue點。
  2. 初始定位：按「設定初始位置」按鈕並選取舞者、點選舞台格子，全部完成後再按一次結束定位。
  3. 舞者走位 Cue：選好舞者與起始拍點 → 按「＋ 新增 Cue」 → 點舞台目標位置 → 點時間軸結束拍。
  4. 燈光漸變 Cue：按「＋ 新增燈光漸變」 → 調整顏色、亮度與區域 → 點時間軸結束拍即（應該）可平滑過渡。
